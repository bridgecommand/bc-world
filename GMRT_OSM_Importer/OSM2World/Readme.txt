Please download the following, and uncompress into this folder, then make sure that the variables in main.py point to the correct locations. 

These are by default:
osm_2_world_exe in osm2world/OSM2World-latest-bin/osm2world-windows.bat
java_home in openjdk-25.0.1_windows-x64_bin/jdk-25.0.1

Download locations:
OSM2World from https://osm2world.org/download/files/latest/OSM2World-latest-bin.zip
Java JDK/JRE from https://jdk.java.net/25/
